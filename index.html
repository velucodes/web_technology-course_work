Fundamentals of the World Wide Web

1. Internet Overview

The Internet is a worldwide network of interconnected computer networks. It enables devices to communicate and exchange data using communication protocols such as TCP/IP.

Computer ↔ Router ↔ Internet ↔ Web Server

2. Fundamental Computer Network Concepts

  • Node: A device connected to a network.
  • IP Address: A logical address used to identify a device.
  • MAC Address: A hardware address associated with a network interface.
  • Router: Forwards data between different networks.
  • Protocol: Rules that define communication between devices.
  • DNS: Converts domain names into IP addresses.

4. Domain Name

A domain name is a human-readable name used to access a website. DNS translates the domain name into an IP address.

www.college.edu → DNS → IP Address → Web Server

5. Web Browsers and Web Servers

A web browser is client software that requests and displays web resources. A web server stores and delivers web resources in response to requests.

Browser HTTP Request → Web Server ← HTTP Response Web Page

6. Working Principle of a Website

  1. The user enters a URL or selects a link.
  2. The browser finds the server using DNS.
  3. The browser sends an HTTP/HTTPS request.
  4. The server processes the request and returns a response.
  5. The browser renders HTML, CSS and JavaScript.
