## Coursework Overview

This repository contains the completed practical work for **Web Technology Assignment I**.

### Questions Completed

1. **Internet and World Wide Web Concepts**
   - Internet overview
   - Computer network concepts
   - URL structure
   - Domain names
   - Web browsers and web servers
   - Working principle of a website
   - Client-side vs server-side scripting

2. **Student Admission Form**
   - HTML5 form elements
   - Different input types
   - Image, video and audio elements
   - CSS3 selectors
   - CSS box model
   - Responsive user interface

3. **Fashion Store Homepage**
   - Backgrounds and borders
   - Text effects
   - CSS animations
   - Multiple-column layout
   - User interface design principles

4. **Student Grade Calculator**
   - Variables and data types
   - Literals
   - Operators
   - Selection and iteration
   - User-defined functions
   - Total, average, grade and pass/fail calculation

5. **Supermarket Billing System**
   - Quantity and unit-price input
   - Total bill calculation
   - 10% discount when the total exceeds ₹2000
   - Final payable amount
   - JavaScript variables, operators, statements and functions

## How to Run

1. Download or clone this coursework.
2. Open the project folder in **Visual Studio Code**.
3. Open any question folder.
4. Run its `index.html` file in a browser.
5. For the best development experience, use the **Live Server** extension in VS Code.
6. For Q4 and Q5, enter the required values and click the calculation button.
